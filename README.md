# Meda Aarthi - Personal Portfolio

A responsive and accessible personal portfolio created for the Full Stack Development (SPC0701CS) Assignment-1.

## Source basis
The content is based only on:
- Resume document supplied by Meda Aarthi
- Portfolio Requirements / Assignment-1 document supplied by the student

No LinkedIn PDF was used because it was not supplied.

## Technology
- HTML5
- CSS3
- Bootstrap 5.3
- JavaScript ES6+
- Bootstrap Icons

## Features
- Semantic portfolio sections
- Responsive mobile-first layout
- Bootstrap navbar, grid, cards, buttons and form
- Dark/light theme switching
- Project filtering
- Client-side contact form validation
- Dynamic success/error messages
- Smooth scrolling
- Back-to-top control
- Accessible labels, focus states and live status messages

## Run locally
1. Download or clone the repository.
2. Open `index.html` in a browser.
3. For the best development experience, use VS Code with Live Server.

No build step is required.

## GitHub
Create a repository and upload:
`index.html`, `style.css`, `script.js`, `README.md`, and the `assets/` folder.

## Vercel deployment
1. Push the project to GitHub.
2. Open Vercel and import the GitHub repository.
3. Framework preset: Other.
4. Build command: leave empty.
5. Output directory: leave empty.
6. Deploy.
